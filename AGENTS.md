# Urban210

- Сайт фитнес-клуба Urban210 (Хабаровск, ООО «Альянс»). Astro 5, без UI-фреймворков и библиотек анимации.
- Перед правкой интерфейса прочитай `DESIGN.md`.
- Цены, часы, адрес и юрданные меняются только в `src/data/*.ts`. Сверяй их с `docs/open-questions.md`: на старом сайте цифры противоречили друг другу.
- Статьи блога не обещают того, чего нет в `src/data/*.ts` (бассейн, скалодром, детская комната, круглосуточная работа, возврат денег).
- Перед публикацией: `npm run build && npm run check`.
- Не меняй адреса страниц: они совпадают со старым сайтом и уже в индексе.
