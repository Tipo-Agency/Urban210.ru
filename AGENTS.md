# Urban210

- Сайт фитнес-клуба Urban210 (Хабаровск, ООО «Альянс»). Next.js 15, Tailwind 4.
- Перед правкой интерфейса прочитай `DESIGN.md`.
- Цены, часы, адрес и юрданные меняются только в `src/data/*.ts`. Сверяй их с `docs/open-questions.md`: на старом сайте цифры противоречили друг другу.
- Перед публикацией: `npm run build && npm test`.
- Не меняй адреса страниц: они совпадают со старым WordPress-сайтом и уже в индексе.
