# Urban210: SEO-план блога на 100 статей

Источник фактов: `src/data/site.ts`, `src/data/pricing.ts`, `src/data/content.ts`, `docs/open-questions.md`. Машиночитаемая версия: `keyword-plan.json`.

## Сводка

- Статей: 100. Пункты 1–6 уже опубликованы, слаги сохранены.
- Интент: информационный 68, локальный 26, коммерческий 6. С явным локальным интентом (Хабаровск, район, адрес): 26.
- Рубрики: Абонементы и клуб 14, Тренажёрный зал 14, Хабаровск 13, Начинающим 12, Групповые программы 10, Набор массы 9, Похудение 8, Восстановление и SPA 7, Для девушек 7, Питание 6.
- Частотность: везде «оценка». DataForSEO (Google Ads и Labs) не отдаёт данные по локации Russia, а основной поиск в регионе идёт через Яндекс. Перед написанием сверить главные запросы в Wordstat (регион Хабаровск и Россия) и при необходимости поменять порядок публикации.

## Как кластеризовали

Метод из скила seo-cluster: запросы сгруппированы по намерению, а не по совпадению слов. Одна статья отвечает на один вопрос; запросы, которые по смыслу закрываются одной страницей (в выдаче почти наверняка одни и те же документы), ушли во вторичные запросы этой статьи. Проверку пересечения топ-10 стоит сделать выборочно, когда будут данные Wordstat и SERP по Яндексу.

Правила:

- Существующие 6 статей забирают свои интенты целиком: первый месяц в зале, выбор клуба, сауна после тренировки, частота и длительность тренировок, зал для девушек (страхи и программа новичка), похудение через связку силовых и кардио. Новые темы рядом с ними сформулированы через другой вопрос.
- Локальные статьи разделены по модификатору: цена, тариф, район, адрес, вокзал, парковка, часы, SPA, вид групповых, аудитория. Общий запрос «тренажерный зал хабаровск» и «фитнес клуб хабаровск» отданы одной странице (n 21), чтобы не было каннибализации.
- Групповые программы: для пилатеса, зумбы, кроссфита, растяжки и стрип-пластики одна локальная статья на направление, информационный запрос «что это» стоит у неё вторичным. Для TRX, Pump, ABS и функционального тренинга отдельные информационные статьи без города, потому что городской спрос по ним мал.
- Медицинские темы (простуда, колени, подростки, 40+ и 50+) поданы как общие правила с отсылкой к врачу, без диагнозов и обещаний.

Не брали: «фитнес с бассейном», «скалодром», «семейный абонемент», «детский фитнес» (нет в клубе или не подтверждено, см. open-questions). Цены и условия, помеченные «уточнить» (персональные 15 300 ₽, «Полный день» 1700 ₽, дневная карта до 16:00, заморозка 30 дней), перед публикацией сверить с клубом.

Существующая статья n 2 имеет title длиной 74 знака; в плане дан короткий вариант до 65 знаков, H1 в файле можно оставить.
