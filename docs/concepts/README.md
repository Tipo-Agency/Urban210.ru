# Концепции главной Urban210

Живые страницы на настоящих фото, видео и данных клуба, закрыты от индексации. Список с превью: `/concepts/`. Лист всех первых экранов: `all-30.jpg` (ранние листы: `all-10.jpg`, `all-20.jpg`). У каждой концепции `NN-desktop.jpg` и `NN-mobile.jpg` (первый экран), `NN-desktop-full.jpg` и `NN-mobile-full.jpg` (вся страница).
