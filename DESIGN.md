# DESIGN.md: Urban210

Основа: фирменный логотип клуба (чёрный и оранжевый) и баннеры акций со старого сайта: чёрно-белое фото, оранжевое свечение, зерно. Подача спортивного бренда: гигантский логотип на первом экране, капс Oswald 700, бегущие строки.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `bg` | `#0b0b0a` почти чёрный | фон сайта |
| `card` / `raise` | `#1a1816` / `#24211e` | карточки, поля |
| `line` | `#322e2a` | разделители |
| `ink` | `#f4efea` | основной текст |
| `muted` | `#a8a097` | второстепенный текст (контраст 7:1 на `bg`) |
| `accent` | `#ff5a1f` | горячий оранжевый из логотипа: кнопки, цифры, финальный блок |
| `paper` | `#f3eee8` | светлые секции (тарифы, FAQ) для ритма страницы |

Светлые секции (`.on-paper`) переопределяют `ink`, `muted`, `line`, поэтому те же утилиты работают на обоих фонах.

## Типографика

- Заголовки: Oswald 500–700, капс, межстрочный 0.95–1.05. Перекликается с трафаретным логотипом.
- Текст: Golos Text 400–600, 17px на телефоне, строка до 68 знаков.
- Шкала через `clamp()`: `--text-hero`, `--text-h2`, `--text-h3`, `--text-lead`.

## Компоненты

- Кнопки: `.btn-accent` (одно главное действие на экран) и `.btn-ghost`. Высота от 52px, радиус 14px.
- Карточки: радиус 20px, рамка `line`, без теней.
- Одна форма на сайт (модальное окно и финальный блок). 3 поля + согласие.
- На телефоне липкая панель: звонок, WhatsApp, «Пробный день за 1 ₽».

## Правила

- Только реальные фото клуба. Стоковые не используем; если фото зоны нет, плитка без фото (как SPA).
- Движение: бегущие строки, появление блоков (`data-reveal`, `data-clip`), счётчики (`data-count`), проявление слогана по словам (`data-words`). Всё в `src/components/motion.tsx` на IntersectionObserver и одном rAF-обработчике. Без JavaScript контент виден сразу, `prefers-reduced-motion` выключает движение.
- Текст первого экрана не анимируем: он LCP-элемент.
- Фото в карточках чёрно-белые (`.duo`), цвет появляется на ховере.
- Зерно: плитка `public/images/grain.webp` поверх страницы. SVG-фильтры и `blur()` на больших слоях не используем: они давали 2 секунды блокировки на телефоне.
- Декоративный гигантский текст (футер, «6:30», «40–50°») рисуется псевдоэлементом `.deco` через `data-text`.
- Нет градиентного текста и эмодзи вместо иконок. Стекло только у плавающей шапки и нижней панели.
- Каждая секция проверяется на ширине 360px с отступами 16px.
