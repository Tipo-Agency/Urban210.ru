# DESIGN.md: Urban210 (Astro)

Основа: двойной шеврон » из логотипа клуба и оранжевый #ff5722 на тёплом графите. Фото и видео зала чёрно-белые, цвет даёт только оранжевый: кнопки, бегущая строка, блок пробного дня, финальная заявка.

Отказались (замечания клиента 28.10.2026): асфальтовая гранж-текстура, копия живого сайта, Lenis и прокрутка-перехват, тяжёлые библиотеки анимации.

## Токены (`src/styles/global.css`)

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0f0c0a` | фон |
| `--card` / `--raise` | `#1e1814` / `#2a221d` | плитки |
| `--ink` / `--muted` | `#f5f0ea` / `#b0a59b` | текст |
| `--accent` | `#ff5722` | кнопки и плоскости, текст на нём `#160d08` |
| `--paper` | `#efe9e2` | светлая секция тарифов |

`.on-paper` и `.on-accent` переопределяют цвета текста, поэтому компоненты работают на любом фоне.

## Шрифты

- Заголовки и цифры: Unbounded 700 (свои файлы в `public/fonts`, кириллица предзагружается).
- Текст: Golos Text Variable, 17px.

## Движение

- Первый экран: заголовок выезжает построчно, на десктопе после загрузки включается ч/б видео; шеврон бренда уезжает вправо, а фото чуть приближается по мере прокрутки (CSS scroll-driven animations, без JS).
- Слоган под бегущей строкой загорается по словам при прокрутке (`data-words`), оранжевые слова выделены звёздочкой в исходном тексте.
- Блоки с `data-rise` всплывают один раз через IntersectionObserver.
- Всё отключается при `prefers-reduced-motion`.

## Скорость

Видео (1,6 МБ) грузится только на десктопе после `load`. Фото через `astro:assets` в AVIF нужной ширины. Карта и 3D-тур загружаются по клику. Метрика и Calltouch через 1,5 с после `load`.
